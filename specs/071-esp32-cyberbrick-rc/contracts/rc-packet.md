# CyberBrick → ESP32 RC 封包契約

- Transport：ESP-NOW 廣播，同一 Wi-Fi 頻道；接收端依配對 ID 過濾。
- Payload：21 bytes。byte 0 為 1–255 配對 ID；後續十個值各佔 2 bytes，小端序有號 16 位。
- 值順序：L1、L2、L3、R1、R2、R3、K1、K2、K3、K4。六軸值須在 0–4095；K 值只接受 0（按下）、1（放開）。
- 僅當長度正好 21、配對 ID 相符且十個值均合法時更新整筆狀態；任一值越界即拒收整包，不刷新最後有效封包時間。不保留來源 MAC。
- 距最後有效封包超過 1500ms 或初始化失敗：已連線=false；搖桿=2048；按鈕=false。
- 產生碼使用 IDF 4.4.7 的三參數接收回呼；回呼中不阻塞、不配置記憶體、不輸出序列訊息。
