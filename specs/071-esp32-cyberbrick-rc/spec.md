# 功能規格：ESP32 接收 CyberBrick RC 訊號

**Feature Branch**: `codex/071-esp32-cyberbrick-rc`\
**Created**: 2026-09-24\
**Status**: 已釐清\
**Input**: 在 ESP32 DevKit 加入實驗性 RC 連線分類，接收本專案 CyberBrick RC 發射端訊號。

## 使用情境與驗收

### 使用情境一：ESP32 接收遙控器資料（P1）

學生選擇 ESP32 DevKit，設定與 CyberBrick 發射端相同的配對 ID 與頻道，在程式中讀取六個搖桿軸及四個按鈕。

**獨立驗收**：兩塊板上傳各自程式後，ESP32 讀值隨遙控器操作改變。

1. **假設** CyberBrick 持續發送且配對 ID、頻道一致，**當** ESP32 接收有效訊號，**則**六軸數值與四個按鈕狀態對應發射端。
2. **假設** 配對 ID 不同、頻道不同或封包無效，**當** ESP32 等待訊號，**則**這些資料不會改變讀值或連線狀態。

### 使用情境二：斷線時安全停止（P1）

學生使用連線狀態、限時等待、搖桿及按鈕積木控制模型；停止發射或初始化失敗時，讀值回到安全預設。

1. **假設** 已經收到有效訊號，**當** 連續 1.5 秒沒有新訊號，**則**連線狀態變成未連線、六軸回傳 2048、按鈕回傳未按下。
2. **假設** 未放置初始化積木或初始化失敗，**當** 程式讀取連線與數值積木，**則**程式仍可執行並回傳安全預設。
3. **假設** 放置限時等待積木，**當** 時間到仍未連線，**則**程式繼續執行。

### 使用情境三：辨識實驗功能與板型限制（P2）

學生在 ESP32 DevKit 工具箱找到獨立的「RC 連線」分類，並能辨識其中功能仍屬實驗性。

1. **假設** 選擇 ESP32 DevKit，**當** 開啟 RC 連線分類，**則**六種接收積木都可選用並有黃色發光虛線標示。
2. **假設** 切換至其他板型，**當** 檢視工具箱，**則**不顯示 ESP32 RC 分類；既有工作區的 RC 接收積木顯示板型警告。
3. **假設** 工作區含 RC 接收積木，**當** 儲存並重新開啟，**則**積木設定與實驗標示仍存在。
4. **假設** 工作區含實驗積木，**當** 展開或收合右上角功能按鈕，**則**黃色驚嘆號持續顯示，並可開啟完整提醒。

### 邊界情況

- 配對 ID 限於 1–255；頻道限於 1–11。搖桿通道為 L1、L2、L3、R1、R2、R3；按鈕為 K1、K2、K3、K4。
- 限時等待為 1–60 秒；逾時後不阻塞程式。
- 工作區同時放置 RC 接收初始化與 Wi-Fi 連線積木時，兩個積木都顯示警告：RC 初始化會斷開既有 Wi-Fi；須先初始化 RC，再連接固定於相同頻道的基地台，否則 RC 接收可能中斷。

## 需求

### 功能需求

- **FR-001**：僅 ESP32 DevKit 工具箱提供獨立「RC 連線」分類，保留分類供未來連線方式擴充。
- **FR-002**：分類提供接收端初始化、限時等待連線、是否連線、讀取搖桿值、映射搖桿值及判斷按鈕是否按下，共六種積木。
- **FR-003**：接收端使用現有 CyberBrick RC 發射積木的配對 ID、頻道及六軸／四按鈕訊號格式；不支援原廠遙控協定。
- **FR-004**：無效、過短、過長或配對 ID 不符的訊號不得改變接收資料與連線狀態；六軸只接受 0–4095、四按鈕只接受 0 或 1，任一值越界即拒收整包且不刷新最後有效封包時間。
- **FR-005**：超過 1.5 秒無有效訊號、未初始化或初始化失敗時，回傳未連線、搖桿 2048、按鈕未按下。
- **FR-006**：限時等待連線必須在指定期限內返回；映射值依搖桿範圍 0–4095 映射至使用者指定範圍。
- **FR-007**：所有六種積木都沿用現有實驗積木標示與提醒，並於非 ESP32 DevKit 顯示板型警告且不產生不相容程式。
- **FR-008**：工具提示說明配對 ID 與頻道必須一致，並說明與 Wi-Fi／MQTT 混用可能發生頻道衝突；工作區同時放置 RC 初始化與 Wi-Fi 連線積木時，兩者須顯示具體的操作順序及同頻道警告。
- **FR-009**：15 個支援語系都提供新分類／積木文字、工具提示與必要警告。

## 成功標準

- **SC-001**：使用者可在 ESP32 DevKit 工具箱找到並使用全部六種積木，其他板型均不顯示該分類。
- **SC-002**：有效的六軸／四按鈕訊號均可讀取；錯誤配對與無效訊號都不改變接收狀態。
- **SC-003**：停止發射後 1.5 秒內，連線狀態與全部讀值回到安全預設。
- **SC-004**：六種積木在工具箱和工作區都呈現現有實驗標示，重新載入後仍能辨識。

## 假設

- 首版只服務現有 CyberBrick RC 發射積木與 ESP32 DevKit；不新增原廠遙控器支援。
- 首版固定頻道獨立使用，不自動協調現有 Wi-Fi／MQTT 功能的頻道。
- 實驗標示沿用專案現有的黃色發光虛線與提醒機制。
