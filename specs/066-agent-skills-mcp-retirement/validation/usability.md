# SC-010 首次使用者可用性驗收

狀態：待外部驗收

SC-010 要求至少 10 位首次使用者在不查看或操作 Skill 設定檔的情況下，各自完成一次 AI 工作區修改，並量測成功率、外部安裝協助與人工排錯需求。這是實際受試者研究，無法由自動測試或單一開發代理誠實替代。

產品端前置條件已完成：Skill 靜默自動建立／更新、零確認與成功通知、正式入口可被代理自動發現、無系統 Node.js／外部 server 需求，以及無效候選自動隔離復原。

T063 保持未勾選，待安排至少 10 位首次使用者後填入：

- 受試者人數與招募條件。
- 成功完成 AI workspace 修改的人數與比例（門檻至少 90%）。
- 需要外部安裝說明的人數。
- 需要人工排錯的人數與原因。
- 每位受試者是否曾查看或操作 `.agents`／`.claude` 設定檔。
