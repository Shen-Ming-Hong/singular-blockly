**Визуальное программирование для Arduino, CyberBrick и fischertechnik TXT Controller прямо в VS Code.**

Собирайте программы в Blockly, сразу смотрите сгенерированный код и загружайте его через PlatformIO, USB, OTA в локальной сети или SSH.

[Установить из VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Singular-Ray.singular-blockly) · [Установить из Open VSX](https://open-vsx.org/extension/Singular-Ray/singular-blockly) · [Документация](../specifications/README.md)

## Как это работает

Эти записи сделаны в настоящем окне VS Code с текущей сборкой расширения.

**1. Откройте редактор и выберите плату.** Нажмите значок Singular Blockly на панели действий и выберите свою плату в списке «Выберите плату».

![Открытие редактора Blockly с панели действий и выбор Arduino Uno](../images/readme/open-editor-and-select-board.gif)

**2. Перетаскивайте блоки и следите за кодом.** Перетащите блоки с панели инструментов в «Настройка» и «Цикл», меняйте значения в раскрывающихся списках и держите `src/main.cpp` открытым рядом с редактором, чтобы видеть, как меняется сгенерированная программа.

![Сборка программы мигания светодиодом перетаскиванием, пока обновляется src/main.cpp](../images/readme/build-program-with-live-code.gif)

**3. Смените язык и тему.** Разверните панель инструментов кнопкой со стрелкой, сразу смените язык редактора в меню с глобусом и переключайте светлую и тёмную тему кнопкой темы.

![Переключение редактора на традиционный китайский и тёмную тему](../images/readme/switch-language-and-theme.gif)

## Отзывы, онлайн-сервисы и использование данных

Используйте кнопку «Отправить отзыв» в редакторе Blockly, выполните **Singular Blockly: Отправить отзыв** из палитры команд или воспользуйтесь средством отчёта о проблемах VS Code. Учётная запись GitHub не нужна. Открытие и заполнение формы не отправляет сетевых запросов; перед отправкой форма показывает всё содержимое и просит явного подтверждения.

Базовая диагностика среды включена по умолчанию, её можно отключить. Недавние структурированные события по умолчанию выключены. Список разрешённых полей не включает исходный код, содержимое рабочей области Blockly, сгенерированный код, имена файлов и папок, пути, идентификаторы компьютера и устройств, последовательные порты, сведения о Wi-Fi и IP, переменные окружения, учётные данные, исходные ошибки и журналы. Один необязательный снимок экрана перекодируется локально, очищается от исходных метаданных, ограничивается 1920 пикселями и 3 МиБ, показывается для предпросмотра и отправляется только после подтверждения.

Для отзывов используется анонимный секрет из VS Code SecretStorage и отдельный сервис Cloudflare D1/R2; для работы сопровождающих используется закрытый репозиторий GitHub. Эта отправка в поддержку, которую запускает сам пользователь, не является телеметрией или аналитикой. Подробнее: [уведомление о конфиденциальности](../../PRIVACY.md), [политика поддержки](../../SUPPORT.md), [условия сервиса отзывов](../../TERMS.md) и [политика безопасности](../../SECURITY.md).

## Почему Singular Blockly?

- **Один визуальный редактор, три способа программирования**: Arduino C++, CyberBrick MicroPython и TXT Controller Python.
- **Загрузка прямо на устройство**: PlatformIO для Arduino, USB или OTA по сопряжённой локальной сети для CyberBrick и SSH для TXT Controller.
- **Инструменты для занятий**: локализованные примеры, виртуальные элементы управления TXT, проверка ввода-вывода, резервные копии и понятная диагностика оборудования.
- **Современный Blockly**: Blockly 13.4.0 с `@blockly/theme-modern`, светлая и тёмная темы, поиск блоков, сенсорное управление, навигация с клавиатуры и понятные подписи элементов — всё встроено и работает без сети.
- **Надёжные файлы проекта**: автосохранение, восстановление из копий, защита от блоков-сирот и проверка внешних изменений рабочей области во время работы.
- **Проекты с поддержкой ИИ**: локальные Agent Skills проекта сообщают агентам программирования текущую плату, формат рабочей области и контракт блоков.

## Быстрый старт

1. Установите Singular Blockly из [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Singular-Ray.singular-blockly) или [Open VSX](https://open-vsx.org/extension/Singular-Ray/singular-blockly).
2. Откройте в VS Code папку с правом записи.
3. Нажмите значок Singular Blockly на панели действий или выполните **Singular Blockly: Открыть редактор Blockly** из палитры команд.
4. Выберите плату и соберите программу из блоков панели инструментов.
5. Откройте сгенерированный файл (например, `src/main.cpp`), чтобы проверить код, а затем нажмите кнопку загрузки на панели инструментов редактора.

После запуска VS Code Singular Blockly начинает готовить в собственном хранилище расширения проверенный Python, PlatformIO Core из протестированного диапазона версий и среду `mpremote`. При открытии редактора Blockly среда проверяется снова, не мешая редактированию. Для Arduino по-прежнему в первую очередь используется поставщик: VS Code использует `platformio.platformio-ide`, а среды Open VSX, например VSCodium, могут использовать `pioarduino.pioarduino-ide`; Singular Core служит запасным вариантом. Пользовательская папка управляемой среды при первом использовании должна быть пустой, чтобы восстановление и очистка не затронули посторонние файлы.

<details>
<summary><b>Установка VSIX без сети</b></summary>

1. Скачайте последний `.vsix` со страницы [GitHub Releases](https://github.com/Shen-Ming-Hong/singular-blockly/releases).
2. Откройте **Extensions: Install from VSIX...** (Расширения: установить из VSIX) в палитре команд.
3. Выберите скачанный файл.

```bash
code --install-extension singular-blockly-X.Y.Z.vsix
```

</details>

<details>
<summary><b>Устранение неполадок CyberBrick по USB</b></summary>

`mpremote` автоматически устанавливается в управляемую среду Singular, которой не нужен системный Python. Откройте **диагностику PlatformIO**, чтобы проверить или восстановить его. Среда поставщика PlatformIO остаётся запасным вариантом для совместимости, и Singular Blockly никогда её не удаляет и не очищает.

</details>

## Поддерживаемые платы

| Плата                         | Генерируемый код | ID в списке  | Загрузка / выполнение                                        |
| ----------------------------- | ---------------- | ------------ | ------------------------------------------------------------ |
| Arduino Uno                   | `src/main.cpp`   | `uno`        | PlatformIO                                                   |
| Arduino Nano                  | `src/main.cpp`   | `nano`       | PlatformIO                                                   |
| Arduino Mega                  | `src/main.cpp`   | `mega`       | PlatformIO                                                   |
| ESP32 Dev Module              | `src/main.cpp`   | `esp32`      | PlatformIO                                                   |
| ESP32-C3 Super Mini           | `src/main.cpp`   | `supermini`  | PlatformIO                                                   |
| CyberBrick                    | `src/rc_main.py` | `cyberbrick` | USB `mpremote` или OTA по сопряжённой LAN → `/app/rc_main.py` |
| fischertechnik TXT Controller | `src/main.py`    | `txt`        | SSH + `python3` → `/tmp/singular_blockly/main.py`            |

Проекты Arduino сохраняют `platformio.ini`; проекты CyberBrick и TXT работают с Python и удаляют этот файл, если он не нужен.

## Основные возможности

### Arduino и ESP32

- Генерирует C++ для Arduino и автоматически синхронизирует `platformio.ini`.
- Компилирует и загружает через PlatformIO с определением порта под конкретную плату и сообщениями об ошибках, в которых сказано, что делать.
- Показывает вывод последовательного порта в терминале VS Code; для проектов ESP32 автоматически включается декодирование исключений.
- Содержит блоки ввода-вывода, ШИМ, сервопривода, мотора с энкодером, Wi-Fi/MQTT, Pixetto, HUSKYLENS и стандартные блоки программирования.
- Принимает на ESP32 DevKit сигналы пульта CyberBrick по ESP-NOW с помощью экспериментальных блоков RC-приёмника.

### CyberBrick

- Генерирует MicroPython для ESP32-C3, включая блоки GPIO, встроенного светодиода, задержек, Wi-Fi, X11/X12 и пульта ESP-NOW.
- По умолчанию используется USB; сопряжённую цель OTA в локальной сети можно настроить в меню с шестерёнкой CyberBrick.
- Первая настройка OTA выполняется по USB. Неудачная загрузка по OTA никогда не переключается на USB автоматически, чтобы код не попал на чужое устройство в классе.
- При загрузке по сети поддерживает совместимые OTA-агенты в актуальном состоянии; предупреждение об обновлении агента не отменяет загрузку основной программы.
- Показывает вывод `print()` MicroPython через `mpremote` в терминале VS Code.
- Позволяет просматривать локализованные примеры CyberBrick, а без сети — встроенные примеры.
- Хранит пароли Wi-Fi, токены OTA и секреты сопряжения в VS Code SecretStorage. Настройка OTA не меняет прошивку, `/boot.py`, WebREPL и другие файлы на устройстве.

[Подробнее о CyberBrick](../specifications/03-hardware-support/cyberbrick-micropython.md) · [Платы расширения](../specifications/03-hardware-support/cyberbrick-expansion-boards.md) · [Сопряжение RC](../specifications/03-hardware-support/cyberbrick-rc.md)

### TXT Controller

- Создавайте один поток настройки и несколько одновременно работающих потоков процессов TXT.
- Загружайте, запускайте и останавливайте программы на Python по SSH.
- Настраивайте и проверяйте подключение, не выходя из редактора Blockly.
- Создавайте перетаскиваемые виртуальные кнопки с постоянными привязками.
- Проверяйте моторы, выходы и датчики во встроенной панели проверки ввода-вывода.

Пароли TXT хранятся в VS Code SecretStorage. По умолчанию используется адрес `192.168.7.2` и имя пользователя `ftc`; сгенерированная программа загружается в `/tmp/singular_blockly/main.py`.

[Подробнее о TXT Controller](../specifications/03-hardware-support/txt-controller.md)

### Работа с помощью ИИ

Локальные Agent Skills проекта сообщают Codex и Claude Code текущую плату, формат рабочей области и контракт блоков, полученный во время выполнения. Пользователю не нужно устанавливать сервер Node.js.

Внешние изменения `blockly/main.json` проверяются в одноразовых средах Blockly, прежде чем попасть в активную рабочую область. Некорректное содержимое помещается в карантин, а последняя корректная рабочая область восстанавливается.

[Agent Skills и безопасность рабочей области](../specifications/06-features/agent-skills.md)

## Настройки

Настройки доступны в интерфейсе параметров VS Code. Значения по умолчанию ниже совпадают с манифестом расширения.

| Параметр                                      | По умолчанию                                  | Назначение                                                 |
| --------------------------------------------- | --------------------------------------------- | ---------------------------------------------------------- |
| `singularBlockly.managedRuntime.path`         | `""`                                          | Необязательная папка для управляемой среды                 |
| `singularBlockly.safetyGuard.suppressWarning` | `false`                                       | Скрыть предупреждение для проектов без Blockly             |
| `singular-blockly.txt.host`                   | `192.168.7.2`                                 | Адрес TXT Controller                                       |
| `singular-blockly.txt.username`               | `ftc`                                         | Имя пользователя SSH для TXT                               |
| `singular-blockly.txt.remotePath`             | `/tmp/singular_blockly/main.py`               | Куда загружать программу на TXT                            |
| `singular-blockly.txt.runtimePort`            | `8080`                                        | Базовый порт панели проверки ввода-вывода TXT              |
| `singular-blockly.cyberbrick.uploadSettings`  | `{ "schemaVersion": 2, "pairedDevices": [] }` | Список устройств CyberBrick для USB / сопряжённого OTA     |

Пароли Wi-Fi, токены OTA, секреты сопряжения и пароли TXT хранятся в VS Code SecretStorage, а не в `settings.json`. В документации и журналах используются заполнители или скрытые значения; никогда не вставляйте настоящие учётные данные в файлы проекта или отчёты об ошибках.

## Требования

- VS Code 1.126.0 или новее либо VSCodium 1.126.04524 или новее. Обновите старые редакторы перед установкой этой версии.
- Папка рабочей области с правом записи.
- Arduino / ESP32: поставщик PlatformIO и расширение C/C++ (`ms-vscode.cpptools`).
- CyberBrick: USB для обычной загрузки и первой настройки OTA; общая локальная сеть нужна только для OTA. После активации расширение готовит `mpremote` в собственной управляемой среде Python и повторно проверяет его при открытии редактора Blockly.
- TXT Controller: сетевой доступ к контроллеру, на устройстве должны быть Python 3 и `ftrobopy`.

Пользователям расширения Node.js не нужен.
